# Исправление защиты

- Антиспам срабатывает начиная с 7 сообщений за 10 секунд (или на 3 одинаковых сообщения / 4 очень быстрых сообщения).
- При срабатывании удаляет сообщение и пытается выдать тайм-аут. Ошибки прав теперь пишутся в `bot.log`.
- Администраторы и боты исключены из проверки; тестируйте с обычного аккаунта без прав администратора.
- Массовые входы: предупреждение начиная с 9-го входа за 60 секунд, с защитой от повторных оповещений. Автоматического бана за массовый вход нет, чтобы не наказывать невиновных.
- Каналы и роли: автоматический откат по-прежнему включается только через `AUTO_REVERT_RAID_ACTIONS=true` и требует прав и доступа к журналу аудита.

## Обязательные настройки Discord

1. Discord Developer Portal -> Bot -> Privileged Gateway Intents: включить **Message Content Intent** и **Server Members Intent**. Перезапустить бота.
2. Выдать роли бота **Manage Messages**, **Moderate Members**, **View Audit Log**, **Send Messages**, **View Channels**.
3. Поднять роль бота выше ролей обычных участников. Бот не может выдавать тайм-аут владельцу сервера, администраторам и участникам с равной/старшей ролью.
4. Проверьте `bot.log` и консоль при тесте с обычного аккаунта. Если намеренно хотите исключить роль/пользователя из защиты, проверьте `ADMIN_ROLE_ID` и `ADMIN_IDS`.
5. `LOG_RAID_CHANNEL_ID` должен указывать на доступный боту канал для логов; при отсутствии ID защита работает, но сообщения в канал логов не отправляются.

Система отзывов Discord и остальные функции бота не изменялись.
