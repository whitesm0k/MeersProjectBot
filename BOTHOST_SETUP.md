# MeersProject Security — Bothost

Архив содержит полный код бота с исправленной генерацией welcome-карточки.
Загружайте содержимое архива в корневую папку приложения Bothost (рядом с bot.py).

Запуск: `python bot.py`
Зависимости: `pip install -r requirements.txt`

В переменных окружения Bothost оставьте прежние BOT_TOKEN, ROLE_..._ID,
WELCOME_CHANNEL_ID и другие настройки из исходного README.
Не вставляйте токен бота в файлы и не загружайте .env в публичный репозиторий.

Изменение: services/welcome_card.py использует локальный шрифт, если он доступен,
а если системные шрифты отсутствуют, использует встроенный шрифт Pillow.
Это предотвращает прежнюю ошибку RuntimeError при создании welcome-карточки.

Проверка: запустите бота и выполните /welcome_test в Discord.
