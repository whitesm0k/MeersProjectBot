# Rust Workshop — настройка

1. Создайте на сервере Discord **канал-форум** (Forum), не обычный текстовый канал. Включите режим сообщества, если Discord требует его для форумов.
2. Скопируйте ID форума и добавьте в `.env`: `RUST_WORKSHOP_FORUM_CHANNEL_ID=123456789012345678`.
3. При необходимости задайте `RUST_WORKSHOP_CATEGORY=Rust Workshop | Проверка` и `RUST_WORKSHOP_MAX_BYTES=20971520`.
4. Дайте боту права Manage Channels, View Channel, Send Messages, Attach Files, Read Message History и Create Public Threads в форуме. Администраторские роли задаются через ADMIN_ROLE_ID и ADMIN_IDS, владелец через OWNER_USER_IDS.
5. Перезапустите бота и выполните `/setup_rust_workshop` в канале публикации панели.
6. Пользователь заполняет четыре текстовых поля и прикрепляет файл в созданном приватном тикете (Discord Modal не поддерживает вложения). Администратор **самостоятельно** проверяет файл антивирусом и другими средствами и только потом нажимает «Проверено — опубликовать».

После успешной публикации бот создаёт ветку форума с файлом и удаляет тикет. При ошибке публикации тикет сохраняется. В Discord может действовать собственный лимит размера вложений; он не обходится настройкой бота.

ВНИМАНИЕ: кнопка «Проверено» фиксирует решение человека, а не автоматический антивирусный анализ. Не запускайте подозрительные файлы на рабочем компьютере. Для надёжного архива файлов используйте отдельное хранилище: после удаления исходного тикета исходное сообщение тоже удаляется, но файл остаётся в опубликованной ветке.
